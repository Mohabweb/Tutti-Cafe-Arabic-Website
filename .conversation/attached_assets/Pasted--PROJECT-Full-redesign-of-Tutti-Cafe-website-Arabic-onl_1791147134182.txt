## 1. TECH STACK (keep it simple)
- Plain HTML + CSS + vanilla JavaScript. No React, no backend, no database.
- Static site served by a tiny Node or Python server, deployable as a Replit Static Deployment.
- All data in JSON files: data/menu.json, data/branches.json, data/site.json. The pages render from these files with JS.
- Folder structure: index.html, menu.html, branches.html, media.html, jobs.html, about.html, css/, js/, data/, assets/ (menu/, branches/, slider/, icons/), scripts/ (scraper).
- Google Fonts via <link>, Lucide icons via CDN, no other heavy libraries.

Data cleaning rules:

- Fix obvious typos and stray characters in Arabic names (e.g. a stray diacritic before "شاي كرك"). Price 0 means "unknown": mark price as null and list it in issues.md instead of showing 0. If a description contains the price/calories text, strip it out.
- Write issues.md listing every anomaly found (price 0, missing image, missing description, duplicates, typos).
- Output: data/menu.json: [{id, category_id, category_name_ar, name, description, image, sizes:[{label,price,calories}], is_favorite}], data/branches.json, data/site.json.

If scraping any page fails, use the fallback facts below so the build never blocks.

## 4. DESIGN DIRECTION
Inspired by a "C minor" coffee-shop hero design: warm, premium, minimal, lots of white space.
- Page background: soft grey-beige (#EFEAE7). Main content sits inside a large white-cream rounded container (border-radius ~28px, subtle shadow), centered with comfortable margins.
- Soft wavy beige shape (#F1ECEA) separating hero from lower sections.
- Faint hand-drawn style coffee-bean illustrations (SVG, ~8% opacity) scattered in section backgrounds.
- Pill-shaped buttons (fully rounded). Primary = dark brown with cream text and a small circular arrow icon that sits inside the button on the end side (flip arrow direction for RTL, arrow points left).
- Cards: white/cream, radius 20–24px, very soft shadow, gentle hover lift (translateY -4px) with 200ms transition.
- Animations: subtle fade-up on scroll (IntersectionObserver), no heavy effects. Respect prefers-reduced-motion.

### Colors (CSS variables in :root)
--brown-900: #3E1D08; --brown-700: #5B2C0E (headings, primary buttons); --brown-500: #8A4B1F;
--caramel: #C98B4A; --accent-yellow: #FFB93B (price badge); --cream: #FBF8F6 (surfaces);
--beige: #F1ECEA; --page-bg: #EFEAE7; --text: #4A3326; --text-muted: #8C7567; --white: #FFFFFF.

### Fonts (Google Fonts, Arabic)
- Headings: "El Messiri" (weights 600, 700). Elegant serif-like feel matching the original design.
- Body/UI/buttons: "Readex Pro" (weights 300, 400, 500, 600).
- Large numbers/stat figures and price badge: "Lalezar" or "Reem Kufi" (choose the one that looks best).
- font-display: swap, sensible Arabic fallbacks (Tahoma, sans-serif). Line-height 1.8 for body Arabic text, 1.3 for big headings.
- Fluid type: h1 clamp(2.4rem, 5vw, 4rem).

### RTL rules
<html lang="ar" dir="rtl">. Use logical CSS properties (margin-inline-start, padding-inline, inset-inline-end, text-align: start). Mirror all layouts: text on the right, imagery on the left in the hero. Mirror directional icons/arrows. Western digits (0-9) are fine for prices and phone numbers; wrap phone numbers in dir="ltr" spans. No English language switch: the site is Arabic only.
